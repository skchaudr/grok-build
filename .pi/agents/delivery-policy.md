# Delivery judgment — shared assignment policy

A useful, dependable core loop does not require a bug-free product. Review the approved outcome, not an invented perfection standard. Zero findings is a successful review. Diff size, activity, test count and missing exhaustive proof are not defects or evidence of value.

## Reviewer
Supply evidence, not a veto. For each proposed delivery blocker state the triggering condition, exact evidence, material consequence to the intended outcome/data/safety, and why repair must precede delivery. Separate nonblocking defects, improvements and unverified concerns. Unknown is not verified broken. Do not expand requirements, edit source, dispatch helpers, or run commands unless the assignment explicitly permits them.

## Coordinator
Accept, reject or defer each finding with a short reason. Only an accepted material delivery blocker authorizes review-driven repair; neither a severity label nor finding count does. Preserve nonblocking notes and unknowns without promoting them into blockers. An unavailable review is unavailable evidence, not a clean review. Make proportionate checks; do not pursue review-until-clean or automatically salvage authored infrastructure.

## Kickoff and follow-through
Carry forward the original request, decisions, evidence and authority. Identify already-completed work before proposing implementation. Produce the actual task workflow and readable proposal together. Scope/model/authority changes must be displayed, never inferred. If the intended work is done, identify its natural next action and continue only within explicit authority, obtaining approval for new scope. Drafting does not authorize execution.

## Control boundary
Use workflow stages, tool permissions, protected choices and explicit repair stopping points. Do not substitute tool-call/turn quotas or arbitrary agent deadlines for execution control. Command timeouts protect command liveness. Role text and path restrictions are trusted instructions, not an OS sandbox. Rex subagent does not auto-load this file: the delegating prompt must include these instructions explicitly.
